# 代码审查

## 关注顺序

1. 正确性 —— 逻辑是否符合意图，边界条件是否处理；
2. 错误处理 —— 失败路径有没有被吞掉；
3. 安全性 —— 注入、越权、敏感信息泄漏；
4. 可读性 —— 命名、结构、重复代码。

## 输出格式

按严重程度从高到低列出问题，每条给出位置、原因与具体改法。不要只说「这里不好」。
