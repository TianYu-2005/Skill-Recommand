# PDF 简历压缩为一页

把多页 PDF 简历重排为单页，优先压缩排版留白，而不是删减经历。

## 步骤

1. 读取 PDF，抽取文本与区块结构；
2. 收紧页边距、字号与行距；
3. 逐段压缩：去空行、合并短行、缩小项目符号缩进；
4. 输出单页 PDF，并回报为了塞进一页做了哪些取舍。

## 注意

先压缩格式，再压缩内容。删掉一条经历之前，先问清这条经历能不能合并。
